🔧 Тестирование API регистрации

Отправка данных студента через API (аналог формы, но напрямую в обработчик).

💳 Формат оплаты:


🎯 Использование API

Endpoint: POST /send.php

Параметры:

  • name — Имя студента
  • age — Возраст (число)
  • course — Название курса
  • certificate_needed — 1 если нужен сертификат, иначе не передавать или 0
  • payment_form — Формат оплаты: online / cash / invoice

📝 Пример curl запроса:

curl -X POST http://localhost/send.php \
-d "name=API Студент&age=22&course=Backend&certificate_needed=1&payment_form=online"
